# 風城（d/fengcheng）設計文件

依使用者提供的新區域設計表（Excel，2026-11-14）製作，是四塊中的第二塊（水月村 → **風城** → 孟家莊 → 天山）。
風城南接水月村，東至天山；將軍府內有八寶樓，大漠八魔即在此樓中。

## 連接

- 城門口 D20 往 south 接水月村石板路 `/d/shuiyue/stone_road`（D22），D22 往 north 接回來。
- 石板路 D14 往 north 接孟家莊十字路口（`/d/mengjia/crossroad`，2026-11-14 孟家莊做好後開通）。
- 東城門 L12 往 `eastup` 接天山霧海 N10（`/d/tianshan/fog`，2026-11-14 天山做好後開通）；往 `northup` 上天山孤崖，孤崖用 `southdown` 下來。
- 城門口 D20 往 up 上城樓 B20（圖層「城樓」），城樓用 down 下來。春風客棧 F18 往 up 上二樓（圖層「二樓」）。

## 字謎與將軍府（使用者決定，2026-11-14）

- 將軍府門衛（H14，2 位）攔住往北進內院廣場的人，只顯示「將軍府門衛把你攔了下來。」。除非這名玩家已經完成小孩的字謎（`quest/fengcheng_riddle`，永久記錄）。
- 字謎小孩（L18 小巷），**不用 ask**：
  1. 玩家走進小巷，小孩過 1 tick 問「要不要來猜個謎語啊？」。
  2. 玩家用 `say` 說「好」「是」「沒問題」「要」「可以」之類，或對小孩做正面表情（點頭、微笑、鼓掌、揮手、鞠躬等）算同意；說到「不」開頭的否定，小孩說一句「不猜就不猜，沒膽子的」。
  3. 小孩隨機出一題「你說說看…是甚麼字？」，玩家用 `say` 說出答案（話裡含正確的字就算對；只說單一個字而答錯時，小孩回「不對不對，再想想看」）。
  4. 答對：小孩拍手笑、說「答對了」，隔 1 tick 湊到耳邊說「偷偷告訴你個秘密，將軍府裡藏了八個鬼喔」，再隔 1 tick 說「門口的守衛不會再攔你啦」。門衛從此放行。
  5. 離開小巷再回來，小孩會重新問起（已經猜對過的人不再問）。
- 十題來自舊資料《八寶樓謎語》（`reference/es2_records/japentery/2008-07-18-2020129068-八寶樓謎語.txt`）：
