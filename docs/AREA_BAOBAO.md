# 八寶樓（d/baobao）設計文件

樓裡住著大漠八魔，從歐陽書房一路單向往上，到頂樓跳窗才能離開。

## 跳窗（頂樓）

`jump 窗戶`：戰鬥中或忙碌時不能跳。跳下去落在將軍府（`/d/fengcheng/general_gate`）。

- 落地站穩的機率 = 閃躲技能 / 300，所以摔倒機率 = 1 − 閃躲/300（使用者決定，2026-11-15）。
- 技能最高算 200（`query_skill` 上限），閃躲 200 的人仍有 33% 機會摔。
- 摔倒：昏迷，並損傷氣（kee）上限的 1/10（`damage_stat`，與一般受傷一樣會隨休養恢復）。

## 物件

鬼境的「枯乾的骸骨」（`obj/skeleton.c`）與「腐爛的男屍」（`obj/corpse.c`）是一般物件，樣子與屍體腐化後的一樣
（名稱、說明相同，不能撿），但不會變灰消失、也不會再變成骸骨。沒有更動屍體系統（`obj/corpse.c`）。

## 網頁地圖（使用者決定，2026-11-15）

- 八寶樓自成一區（`map/area`：八寶樓），所有房間設 `map/mode` 為 `maze`。
- 靜態地圖只放連接位置：歐陽書房 `/d/baobao/study` 擺在內院廣場北邊（x 4、y −13），
  內院廣場 ↔ 歐陽書房的兩條出口；其餘七間不在靜態地圖裡，不做地圖對照。
- 玩家走出風城、進入八寶樓時，地圖依「不同區域」的規則，把歐陽書房畫成區域交界的顏色；
  進入八寶樓之後，每次只顯示目前所在的房間。
