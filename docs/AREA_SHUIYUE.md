# 水月村（d/shuiyue）設計文件

依使用者提供的新區域設計表（Excel，2026-11-14）製作。整張表是一個大區域，分四塊一個個做：**水月村（本批，17 間）**、風城、孟家莊、天山。
水月村位於雪亭鎮與風城之間，附近有丱天樹、水月瀑布兩大景觀，村民習慣恬靜的生活，近幾年有巨鳥出沒，雖不致災但也讓村民不少擔心。

## 連接

- 雪亭鎮 `/d/snow/npath2`（溪邊小路）往 north → 上山小路 D34（`mountain_path2`）；D34 往 south 回 `npath2`。`npath2` 的敘述不改。
- D22 石板路往 north 要接風城城門口（風城尚未製作，暫不開出口）。
- 水月村的 D 欄是一條主幹：D34、D32、D30、D28、D26、D24、D22 由南往北。上山小路用 `northup`／`southdown`（上坡、下坡）。
- **D22 沒有往東、F22 沒有往西的出口**（使用者指示）；D22 敘述裡「從東邊林子隱約傳來流水沖擊岩壁的悶響」只是暗示瀑布就在附近。
