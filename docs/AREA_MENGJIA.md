# 孟家莊（d/mengjia）設計文件

依使用者提供的新區域設計表（Excel，2026-11-14）製作，是四塊中的第三塊（水月村 → 風城 → **孟家莊** → 天山）。
孟家莊多年前由天朝的一位開國將軍、五虎斷門刀的創始人孟翔溪在此立足，代代相傳至今更像是武林世家而非軍系一脈。
孟家莊並未開宗立派，但家傳武功仍是江湖一絕，相當多人既敬畏又垂涎。地處天朝北面，自成一格、偏安一隅。

## 連接

- 十字路口 D12 往 south 接風城石板路 `/d/fengcheng/stone_road1`（D14），D14 也補上往 north 的出口。
- **暗道**：客棧二樓用指令 `push 床板` 進暗道；暗道往 `up` 回客棧二樓、往 `north` 到密林 F10（**單向**：密林沒有往暗道的出口）。
  暗道在網頁地圖上是獨立圖層「暗道」，只顯示單一格，仍算孟家莊區域，不做區域轉換換色。
- **墓室**：祖墳用指令 `roll 石像` 下到墓室（圖層「地下」）；墓室往 `up` 回祖墳。

## 武功：五虎斷門刀

孟家兄弟專用，玩家不能學，5 招加絕招『五 虎 斷 門』（NPC 出招時 10% 觸發，必中，對手 delay 3 tick，亮黃色敘述）。
設計與實作見 `docs/martial_arts/孟家_五虎斷門刀.md`；技能檔 `daemon/skill/five-tiger_blade.c`。
