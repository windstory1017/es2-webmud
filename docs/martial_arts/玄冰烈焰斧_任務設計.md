# 玄冰烈焰斧：取得任務「紫煙鎮血案」設計

狀態：**已製作（2026-11-18）**：民宅線索（`d/ziyan/house.c`）、血書／官印／密函（`d/ziyan/obj/`）、趙弘春掉落（`custom/legacy_npc/zhao_hong_chun.c`）、程槐對話與傳授（`custom/legacy_npc/cheng_huai.c`）。
來源：使用者提供故事大綱（2026-11-18）；舊資料見 `reference/es2_records/es2tips/2014-03-16-驂龍翔-程槐-趙弘春.txt`。
範圍：這份只談「怎麼拿到玄冰烈焰斧」。斧法本身（招式、特攻、強度）見 `docs/martial_arts/玄冰烈焰斧.md`。

## 一、故事（來龍去脈）

1. **景隆錢莊**的一批鏢銀經過酉縣。押鏢的鏢師是**魏長青**（使用者確認 2026-11-18），程槐是他的結義兄弟，也是同一趟鏢的鏢師。
2. 縣令**趙弘春**與山賊勾結，山賊半路劫鏢，兩邊分贓。劫鏢時程槐身受重傷，拚死逃回紫煙鎮，躲進窄街的茅屋養傷。
3. 魏長青回到紫煙鎮後，趙弘春為了滅口、掩蓋劫鏢的真相，反咬他「監守自盜、私通山賊」，派人把他一家上下殺光，官府草草清洗、貼上封條了事，就是現在的民宅兇案。
4. 魏長青臨死前，在書櫃旁留下血手印，把一封血書藏進書櫃，要交給程槐。程槐重傷、又被縣衙盯著，不敢露面，一直不知道這封信的存在。
5. 玩家搜出真相、為民除害，找到程槐當見證。程槐感念玩家替魏家報了仇，把家傳的**玄冰烈焰斧**傳給玩家。

> 舊資料說趙弘春「處心積慮想消滅雲鶴山的盜匪」，這正好當作他**對外的說法**：表面剿匪，私底下與賊人分贓。
> 舊資料說程槐「看起來臉色不太好，身上受了重傷」，與劇情吻合，不用改。

## 三、任務流程

進度存在玩家身上：`quest/ziyan_axe`（數字，完成後永久保留）。

| 進度 | 意義 | 怎麼進入 |
|---|---|---|
| 0 | 未開始 | 預設 |
| 1 | 查案中 | 在民宅搜出血書 |
| 2 | 案情大白 | 三條線索都找齊，且拿到血書 |
| 3 | 縣令伏誅 | 在趙弘春身上取得官印（密函另外掉，不影響進度） |
| 4 | 完成 | 向程槐交出血書與官印，並親口承認殺了縣令，程槐證實；完成當下進度與各項記號清掉，只留永久記號 `quest/ziyan_axe_done`（見文末「可以一直重解」） |

### 第一步：民宅搜索（進度 0 → 2）

現有的 `search` → 血手印 → `search 書櫃` → 血書**照舊**，再補三處可搜的地方。每處只能各發現一次（每位玩家一次，記在玩家身上，不是房間）。

| 搜索處 | 發現什麼 | 讓玩家知道 |
|---|---|---|
| `search 地板` | 石板縫裡塞著半張被血泡過的鏢單 | 屋主魏長青是景隆錢莊的鏢師，鏢銀在酉縣境內被劫 |
| `search 封條` | 門板上的封條與告示殘角，蓋著縣衙官印 | 官府的說法是「監守自盜、私通山賊」，簽發的是縣令趙弘春 |
| `search 牆縫` | 牆縫裡嵌著半截黑羽箭 | 殺人的不是官差，是山賊慣用的箭；官府「破案」得太快 |

三處都找齊、又拿到血書時，玩家心裡串起全貌（一次性敘述，見第六節）：進度設為 2。順序不限，血書最後拿也行。

`look` 房間裡提到這些東西時要帶指令提示，寫法照 CLAUDE.md：「…或許可以翻找 (search) 看看」。

### 第二步：討公道（進度 2 → 3）

- 玩家自行決定怎麼進縣衙：敲鼓被架進大堂、按金蟾眼睛拿石鑰匙、開內廳木門，路線**完全不變**。
- 在內廳斬殺趙弘春。他一進場就會喊捕快，所以玩家要先料理捕快或與其周旋。
- 進度 ≥ 2 的玩家擊殺趙弘春後，屍體裡多一枚**縣令官印**與一份**密函**（見第五節）；官印是「人已伏誅」的憑證，任務必要；密函是山賊回覆趙弘春的信，只用來加深故事，任務不需要；進度不到 2 的玩家擊殺他不掉。
- 殺了縣令不會讓任務結束，要找到程槐證明。

### 第三步：找到程槐（進度 3 → 4）

- 程槐在窄街的茅屋（`enter 茅屋`），本來就在，但玩家不知道他是誰。
- **線索來源**：窄街房間敘述已寫「血跡斷斷續續地一路延伸到茅屋門口」，`look 茅屋` 也提示可 `enter`，玩家順著血跡就能找到，**不需要新增線索，也不動藥鋪掌櫃**（使用者指示 2026-11-18）。
- 玩家進茅屋，把**血書與官印**交給程槐（`give`），兩樣齊了才進入證實。順序不限，只交一樣時程槐照現有物品回應（見第四節），物品由程槐收下。密函不必交；玩家若拿給程槐看或交出，程槐會有額外反應，但不影響進度。
- **官印是最後的關鍵**：程槐收到官印時，會追問「你殺了那個狗官？」，進入等待回答的狀態。
- 玩家要**用說話或表情表示肯定**才算數，做法同風城字謎小孩 `d/fengcheng/npc/child.c`：
  - `say` 說出肯定的話：「是」「對」「沒錯」「殺了」「不錯」「當然」等。
  - 做出正面的表情：`nod`、`smile`、`grin`、`bow` 等。
  - 否定或答非所問（例如 `say 不是`、`shake`）：程槐不信，請玩家想清楚再回答。離開茅屋再回來，他會重新問起。
- 肯定後，程槐才證實全案，進入第四步。

### 第四步：傳授（進度 4）

- 程槐說明玄冰烈焰斧的來歷，傳授給玩家。
- 傳授方式照駱雲峰的作法：NPC 覆寫 `acquire_skill()`，檢查 `quest/ziyan_axe >= 4` 與斧法檔的 `valid_learn()`，通過後直接補到剛好學成。
- 完成後可重複向程槐請益（只教一次入門，之後靠玩家自行練功，同其他共通武功）。

## 四、NPC 對話草稿

規則（CLAUDE.md 2026-11-14）：一行不斷行、說話用 `command("say …")`、多用 `emote`、有需要才停 1 tick。
遊戲裡的字不提等級數字、不提指令。

### 程槐（茅屋）

| 時機 | 內容 |
|---|---|
| 進度不到 2 的人走進茅屋 | `emote 撐著身子坐直，一手悄悄按住背後的斧柄，冷冷地打量著你。` ／ `say 這裡沒有你要找的人，請回吧。` |
| 進度 ≥ 2、尚未交東西 | `emote 目光落在你身上，神色一動。` ／ `say 你是從魏家來的？` ／ `say 長青他……罷了，我身上有傷，進不了縣衙，沒有憑據，說什麼也沒人信。` |
| 交出血書（尚缺官印） | `emote 雙手發顫地接過血書，指尖撫過那一道道血痕，眼眶漸漸紅了。` ／ `say 這是長青的字，他臨死還惦記著我。` ／ `say 光憑這封信，還扳不倒趙弘春，你若有膽，去取他那方從不離身的縣令官印來。` |
| 交出密函（額外反應，不影響進度） | `emote 展開信紙細細讀過，臉色鐵青，握信的手背上青筋暴起。` ／ `say 原來他們早就勾搭上了，連分贓的日子都白紙黑字寫著。` |
| 官印與血書都交了（先後不限） | `emote 接過沉甸甸的官印，手指微微發抖，雙眼死死盯著印面。` ／ `say 這是趙弘春的縣令官印，從不離身。` ／ `say 你殺了那個狗官？` |
| 肯定回答（say 是、對，或 nod 等） | `emote 重重地吐出一口長氣，眼角隱隱泛起淚光。` ／ `say 好！好！長青九泉之下也能瞑目了。` ／ `say 我程槐欠你一個天大的人情。` |
| 否定或答非所問 | `emote 眉頭一皺，目光冷了下來。` ／ `say 這是大事，你想清楚了再回答我。` |
| 已有官印但缺血書 | `say 官印我認得，可是光有官印，長青的冤屈還說不明白，他留下的東西呢？` |
| 傳授時 | `emote 解下背上的重斧，在掌心緩緩摩挲。` ／ `say 這把玄冰烈焰斧是我程家世代相傳的家學。` ／ `say 如今我身負重傷，再也握不動它，與其埋沒，不如傳給你這樣的人。` |
| 完成後再來 | `say 恩公又來了，斧法的訣竅，我已盡數相告，往後就看你自己的火候了。` |

---|---|
| 進度 ≥ 2 的玩家說起程槐或遞上血書 | `emote 左右張望一番，把你拉到櫃檯後頭。` ／ `say 這幾日是有個渾身是傷的壯漢，三天兩頭來抓傷藥。` ／ `say 他就住窄街北邊那間茅屋，你小心些，別讓縣衙的人瞧見。` |
| 其他人 | 照現有行為 |

### look 密函（山賊回覆趙弘春的角度）

以山賊頭目的口吻回信，口氣江湖、直白，不提時辰。依遊戲排版斷行（第一行縮排四格）：

```
    趙大人台鑒：來信已悉。那批鏢銀共計若干，點數無誤，已照前議分作
七三，三成留在山上弟兄喝酒，七成明日便著人送進縣衙後門。魏長青那廝
押鏢有些門道，弟兄們折了幾人才拿下，大人既說要他一家老小不留活口，
這等髒活，山上自有人替大人辦妥。往後景隆錢莊的鏢再過酉縣，咱們照舊
放一條路給大人，只盼大人在縣衙裡替山上多遮掩幾分，莫讓官兵進山來。
    山上人拜上。
```

- 重點：山賊親口提到分贓比例、劫了魏長青押的鏢、答應替縣令滅魏家滿門、往後合作。
- 與血書字跡模糊不同，密函的字跡是清楚的；玩家讀了會更明白魏家之冤，**但任務進度不需要它**。
- 寫法再改成不提明確比例也可以；比例只是劇情細節，請你定。
- 內文標點與用字都用 Big5 常用字，製作時照樣跑 `tools/check_big5_text.py`。

## 六、遊戲文字草稿（民宅線索）

均為單行敘述，不提等級、不寫指令（房間詳細物件的指令提示例外，會帶括號）。

- `search 地板`：「你蹲下身仔細摸索，從石板縫裡抽出半張被血泡得發硬的紙，上面依稀是景隆錢莊的鏢單，押鏢人一欄寫著魏長青，鏢銀的去向卻被血漬糊成了一團。」
- `search 封條`：「你湊近細看門板上殘存的封條與告示，上頭寫著魏長青監守自盜、私通山賊，落款蓋著縣衙的大印，簽押的正是縣令趙弘春。」
- `search 牆縫`：「你在牆縫裡摸出半截黑羽箭，箭桿粗糙，絕不是官府的制式，倒像是山賊慣用的東西。」
- 三處與血書齊備時（只出現一次）：「你把鏢單、告示與黑羽箭擺在一起，心裡漸漸有了輪廓：魏長青押的鏢被山賊劫了，縣令趙弘春與賊人同流合污，事後為了滅口，反誣魏長青私吞鏢銀，連他全家都不放過。這封血書，想必是要交給某個人的。」
- 已找過的處所再搜：「你把這裡又翻了一遍，再也找不到什麼。」

## 七、斧法的學習條件

- 技能 id：`ice-fire axe`（舊站名稱表已有「玄冰烈焰斧」），預定放 `daemon/skill/` 用新版武功共用引擎。
- 學習條件：任務完成（`quest/ziyan_axe` 為完成）。**不另設雙手斧術等基礎數字**（使用者指示 2026-11-18）。
- **僅武者可學**（使用者指示 2026-11-18）：斧法檔的 `valid_learn()` 檢查職業為武者（fighter），其他職業向程槐求教時，程槐婉拒，說法用江湖語氣，不提「職業」「等級」字眼，例如「這路斧法是程家祖傳的拳腳功夫，需有武者的底子才練得來」。種族、性別不限。

## 九、邊界情況

- **多人同時**：血書、線索、密函都以玩家為單位判定，不互相搶。
- **趙弘春重生**：房間重置後會再出現，所以玩家可以重複擊殺，但官印與密函只在進度剛好是 2 時各掉一次。
- **程槐被打死**：可以被殺（使用者指示 2026-11-18）。他死後房間重置會重新出現，已完成任務的進度永久保留，不會被堵死；被他重新刷出後不記得先前的對話狀態，玩家重新交物品即可。被殺時不掉玄冰烈焰斧的秘笈，也不會因此直接學到斧法。
- **血書被丟掉或搶走**：進度已到 2 之後，血書丟了可回民宅重搜（每次重置一封）；若血書已被他人取走，下個重置再來。
- **官印遺失**：進度 3 的玩家丟了官印，可重新殺趙弘春再取一次；密函遺失不影響進度。
- **字元相容**：所有文字只用 Big5 有的字；完成後跑 `tools/check_big5_text.py`。

## 可以一直重解（使用者指示，2026-11-18）

任務**不限定只能解一次**：

- 完成（程槐證實）的當下，把 `quest/ziyan_axe`（進度）、`quest/ziyan_axe_clue`（線索）、`quest/ziyan_axe_letter`、`quest/ziyan_axe_seal`、`quest/ziyan_axe_secret`（密函）全部清掉，只留永久記號 `quest/ziyan_axe_done`。
- 清掉之後玩家可以重新搜民宅、擊殺趙弘春（房間重置後會再出現）、再交一次血書與官印。
- 每解完一次：武者且沒學過玄冰烈焰斧 → 傳授；不是武者或已學過 → 道謝並送一把闇雲雙刃斧（每次都送）。
- 向程槐求教斧法看的是 `quest/ziyan_axe_done`；學過之後重解，程槐改送斧頭。
- 平常（沒在重解）走進茅屋：解過的玩家聽到「恩公又來了…」，沒解過的玩家照舊被冷冷打發；重解途中依進度有對應的反應。
- 第一次解完後再次進度為 0，所以重解時 `search 地板` 等線索會再顯示一次。
