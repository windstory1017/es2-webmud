## 一、故事（來龍去脈）

1. **景隆錢莊**的一批鏢銀經過酉縣。押鏢的鏢師是**魏長青**（本文暫名，可改），程槐是他的結義兄弟，也是同一趟鏢的鏢師。
2. 縣令**趙弘春**與山賊勾結，山賊半路劫鏢，兩邊分贓。劫鏢時程槐身受重傷，拚死逃回紫煙鎮，躲進窄街的茅屋養傷。
3. 魏長青回到紫煙鎮後，趙弘春為了滅口、掩蓋劫鏢的真相，反咬他「監守自盜、私通山賊」，派人把他一家上下殺光，官府草草清洗、貼上封條了事，就是現在的民宅兇案。
4. 魏長青臨死前，在書櫃旁留下血手印，把一封血書藏進書櫃，要交給程槐。程槐重傷、又被縣衙盯著，不敢露面，一直不知道這封信的存在。
5. 玩家搜出真相、為民除害，找到程槐當見證。程槐感念玩家替魏家報了仇，把家傳的**玄冰烈焰斧**傳給玩家。

> 舊資料說趙弘春「處心積慮想消滅雲鶴山的盜匪」，這正好當作他**對外的說法**：表面剿匪，私底下與賊人分贓。
> 舊資料說程槐「看起來臉色不太好，身上受了重傷」，與劇情吻合，不用改。

## 三、任務流程

進度存在玩家身上：`quest/ziyan_axe`（數字，完成後永久保留）。

| 進度 | 意義 | 怎麼進入 |
|---|---|---|
| 0 | 未開始 | 預設 |
| 1 | 查案中 | 在民宅搜出血書 |
| 2 | 案情大白 | 三條線索都找齊，且拿到血書 |
| 3 | 縣令伏誅 | 在趙弘春身上取得官印與密函 |
| 4 | 完成 | 向程槐交出血書、密函與官印，並親口承認殺了縣令，程槐證實 |

### 第一步：民宅搜索（進度 0 → 2）

現有的 `search` → 血手印 → `search 書櫃` → 血書**照舊**，再補三處可搜的地方。每處只能各發現一次（每位玩家一次，記在玩家身上，不是房間）。

| 搜索處 | 發現什麼 | 讓玩家知道 |
|---|---|---|
| `search 地板` | 石板縫裡塞著半張被血泡過的鏢單 | 屋主魏長青是景隆錢莊的鏢師，鏢銀在酉縣境內被劫 |
| `search 封條` | 門板上的封條與告示殘角，蓋著縣衙官印 | 官府的說法是「監守自盜、私通山賊」，簽發的是縣令趙弘春 |
| `search 牆縫` | 牆縫裡嵌著半截黑羽箭 | 殺人的不是官差，是山賊慣用的箭；官府「破案」得太快 |

三處都找齊、又拿到血書時，玩家心裡串起全貌（一次性敘述，見第六節）：進度設為 2。順序不限，血書最後拿也行。

`look` 房間裡提到這些東西時要帶指令提示，寫法照 CLAUDE.md：「…或許可以翻找 (search) 看看」。

### 第二步：討公道（進度 2 → 3）

- 玩家自行決定怎麼進縣衙：敲鼓被架進大堂、按金蟾眼睛拿石鑰匙、開內廳木門，路線**完全不變**。
- 在內廳斬殺趙弘春。他一進場就會喊捕快，所以玩家要先料理捕快或與其周旋。
- 進度 ≥ 2 的玩家擊殺趙弘春後，屍體裡多一枚**縣令官印**與一份**密函**（見第五節）；官印是「人已伏誅」的憑證，密函是「勾結」的憑證；進度不到 2 的玩家擊殺他不掉。
- 殺了縣令不會讓任務結束，要找到程槐證明。

### 第三步：找到程槐（進度 3 → 4）

- 程槐在窄街的茅屋（`enter 茅屋`），本來就在，但玩家不知道他是誰。
- **線索來源（擇一，建議 A）**：
  - A. 玩家進度 ≥ 2 時，對藥鋪掌櫃說起程槐，或把血書給掌櫃看，掌櫃壓低聲音說最近有個渾身是傷的壯漢，每隔幾天就來買傷藥，人就住在窄街那間茅屋。
  - B. 血書信封上能辨出「槐」字，窄街茅屋的血跡把玩家引過去（現有窄街敘述已有血跡）。
- 玩家進茅屋，把**血書、密函、官印**交給程槐（`give`），三樣齊了才進入證實。順序不限，只交部分時程槐照現有物品回應（見第四節），物品由程槐收下。
- **官印是最後的關鍵**：程槐收到官印時，會追問「你殺了那個狗官？」，進入等待回答的狀態。
- 玩家要**用說話或表情表示肯定**才算數，做法同風城字謎小孩 `d/fengcheng/npc/child.c`：
  - `say` 說出肯定的話：「是」「對」「沒錯」「殺了」「不錯」「當然」等。
  - 做出正面的表情：`nod`、`smile`、`grin`、`bow` 等。
  - 否定或答非所問（例如 `say 不是`、`shake`）：程槐不信，請玩家想清楚再回答。離開茅屋再回來，他會重新問起。
- 肯定後，程槐才證實全案，進入第四步。

### 第四步：傳授（進度 4）

- 程槐說明玄冰烈焰斧的來歷，傳授給玩家。
- 傳授方式照駱雲峰的作法：NPC 覆寫 `acquire_skill()`，檢查 `quest/ziyan_axe >= 4` 與斧法檔的 `valid_learn()`，通過後直接補到剛好學成。
- 完成後可重複向程槐請益（只教一次入門，之後靠玩家自行練功，同其他共通武功）。

## 四、NPC 對話草稿

規則（CLAUDE.md 2026-11-14）：一行不斷行、說話用 `command("say …")`、多用 `emote`、有需要才停 1 tick。
遊戲裡的字不提等級數字、不提指令。

### 程槐（茅屋）

| 時機 | 內容 |
|---|---|
| 進度不到 2 的人走進茅屋 | `emote 撐著身子坐直，一手悄悄按住背後的斧柄，冷冷地打量著你。` ／ `say 這裡沒有你要找的人，請回吧。` |
| 進度 ≥ 2、尚未交東西 | `emote 目光落在你身上，神色一動。` ／ `say 你是從魏家來的？` ／ `say 長青他……罷了，我身上有傷，進不了縣衙，沒有憑據，說什麼也沒人信。` |
| 交出血書（尚缺其他憑證） | `emote 雙手發顫地接過血書，指尖撫過那一道道血痕，眼眶漸漸紅了。` ／ `say 這是長青的字，他臨死還惦記著我。` ／ `say 光憑這封信，還扳不倒趙弘春，你若有膽，去取他與山賊往來的憑證來。` |
| 交出密函（尚缺其他憑證） | `say 這是趙弘春的私印沒錯，可長青的冤屈還缺一個見證。` ／ `say 你可曾在魏家找到他留下的東西？` |
| 交出官印 | `emote 接過沉甸甸的官印，手指微微發抖，雙眼死死盯著印面。` ／ `say 這是趙弘春的縣令官印，從不離身。` ／ `say 你殺了那個狗官？` |
| 肯定回答（say 是、對，或 nod 等） | `emote 重重地吐出一口長氣，眼角隱隱泛起淚光。` ／ `say 好！好！長青九泉之下也能瞑目了。` ／ `say 我程槐欠你一個天大的人情。` |
| 否定或答非所問 | `emote 眉頭一皺，目光冷了下來。` ／ `say 這是大事，你想清楚了再回答我。` |
| 已有官印但缺血書或密函 | `say 官印我認得，可是光有官印，長青的冤屈還說不明白，其他憑證呢？` |
| 傳授時 | `emote 解下背上的重斧，在掌心緩緩摩挲。` ／ `say 這把玄冰烈焰斧是我程家世代相傳的家學。` ／ `say 如今我身負重傷，再也握不動它，與其埋沒，不如傳給你這樣的人。` |
| 完成後再來 | `say 恩公又來了，斧法的訣竅，我已盡數相告，往後就看你自己的火候了。` |

### 藥鋪掌櫃（線索 A）

| 時機 | 內容 |
|---|---|
| 進度 ≥ 2 的玩家說起程槐或遞上血書 | `emote 左右張望一番，把你拉到櫃檯後頭。` ／ `say 這幾日是有個渾身是傷的壯漢，三天兩頭來抓傷藥。` ／ `say 他就住窄街北邊那間茅屋，你小心些，別讓縣衙的人瞧見。` |

## 六、遊戲文字草稿（民宅線索）

均為單行敘述，不提等級、不寫指令（房間詳細物件的指令提示例外，會帶括號）。

- `search 地板`：「你蹲下身仔細摸索，從石板縫裡抽出半張被血泡得發硬的紙，上面依稀是景隆錢莊的鏢單，押鏢人一欄寫著魏長青，鏢銀的去向卻被血漬糊成了一團。」
- `search 封條`：「你湊近細看門板上殘存的封條與告示，上頭寫著魏長青監守自盜、私通山賊，落款蓋著縣衙的大印，簽押的正是縣令趙弘春。」
- `search 牆縫`：「你在牆縫裡摸出半截黑羽箭，箭桿粗糙，絕不是官府的制式，倒像是山賊慣用的東西。」
- 三處與血書齊備時（只出現一次）：「你把鏢單、告示與黑羽箭擺在一起，心裡漸漸有了輪廓：魏長青押的鏢被山賊劫了，縣令趙弘春與賊人同流合污，事後為了滅口，反誣魏長青私吞鏢銀，連他全家都不放過。這封血書，想必是要交給某個人的。」
- 已找過的處所再搜：「你把這裡又翻了一遍，再也找不到什麼。」

## 九、邊界情況

- **多人同時**：血書、線索、密函都以玩家為單位判定，不互相搶。
- **趙弘春重生**：房間重置後會再出現，所以玩家可以重複擊殺，但官印與密函只在進度剛好是 2 時各掉一次。
- **程槐被打死**：他是友善 NPC，玩家對他動手會有後果，是否保護他（不可被殺）請你定。
- **血書被丟掉或搶走**：進度已到 2 之後，血書丟了可回民宅重搜（每次重置一封）；若血書已被他人取走，下個重置再來。
- **官印或密函遺失**：進度 3 的玩家丟了其中一樣，可重新殺趙弘春再取一次。
- **字元相容**：所有文字只用 Big5 有的字；完成後跑 `tools/check_big5_text.py`。

## 十、待你確認

1. **受害者姓名與關係**：魏長青、程槐的結義兄弟，可以嗎？也可以換名字，或改成程槐的恩師、親戚。
2. **山賊是誰**：維持不點名最單純（「山上的人」）。若要點名，選項是密林賊窩（但大統領口口聲聲痛罵官兵，兩邊矛盾）或雲鶴山（舊資料說是趙弘春的死對頭，不如當作他對外的說法）。我建議不點名。
3. **「找到程槐」的線索**：藥鋪掌櫃（A）還是血書信封加血跡（B）？建議 A。
4. **證明用的東西**：已改成「血書＋密函＋官印」三樣加口頭承認；是否要精簡成官印加血書？
5. **程槐能不能被殺**：建議設成不可被殺，免得玩家把任務堵死。
6. **斧法學習條件**與開放對象（見第七節）。
7. **血書的敘述**：維持使用者定稿（似字非字），玩家要靠線索拼出案情；這樣可以嗎？
