# 六陰絕識劍（six-dao-sword，左手劍法）

狀態：**設計草案，待使用者確認後才寫程式**（2026-11-15）。來源：使用者指示；敘述依 `武俠敘述風格指南.md` 撰寫。

## 定位

- 左手劍法，走「無情、絕棄」的意象：招名取自「絕X棄X」，劍意空靈、不帶殺意、不講章法。
- 前例：傲梅暗劍訣（`冷梅莊_劍士武功.md`），同樣 enable 在副手劍。
- 90 級起習得兩項特攻：【天譴劍式】（命中後搶攻）、【血噬劍式】（未命中時的必中追擊）。

- 第四招備選名稱：「絕情棄念」「絕欲棄執」。

## 特攻（90 級起習得）

### 【天譴劍式】：命中後再搶攻

- 條件：這一招**命中**（造成傷害）後，機率 30%。
- 效果：再搶攻一招左手劍法（隨機一招、一般攻擊，可被閃躲、格擋）；搶攻的那一招不再觸發特攻。

> $N招式尚未使老﹐卻已看破$n的套路﹐突施「天譴劍式」攻其不備﹗

### 【血噬劍式】：未命中時的追擊

- 條件：這一招**沒命中**（沒造成傷害：被閃開、被格開都算）時，機率 30%。
- 效果：一擊「不可防禦」傷害，等同普攻 150%。

> $N抓住$n招式之間的破綻﹐以「血噬劍式」貫穿$n週身經脈﹗

## 練成敘述（草案）

> 你終於練成了六陰絕識劍﹐劍意空靈﹐竟隱隱有了萬念皆絕之感。

## 待使用者確認

1. 第四招「絕巧棄利」與數值是否可用。
2. 「不可防禦」是只不能閃躲、格擋（防具照樣減傷，同傲梅暗劍訣），還是連防具也無視。
3. 特攻機率 30% 是固定值，還是像傲梅暗劍訣一樣隨等級成長。
4. 搶攻、追擊的耗精（建議：搶攻比照普攻 100%，血噬 150%）。
5. 可 enable 的基本技能（副手劍；要不要也含副手匕首）。
6. 取得方式、學習條件、練成等級、練功獎勵（武術造詣、武學之道）、是否限門派。
7. 技能代碼 `six-dao-sword`：現有 `six-chaos-sword.c`，名稱相近但不衝突，確認沿用。
