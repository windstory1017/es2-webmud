# 傲劍訣：景愈濤戰鬥敘述擷取

資料來源：影片「柳東蘆對景愈濤」的逐字稿（claude.ai artifact BiREjFJzaqvzRNi98stKvp，舊站 /u/z/zorg/workroom，戰鬥 00:16 – 01:21）。
景愈濤持古岳風刃，門派古劍門，使用傲劍訣。以下只擷取**景愈濤自己**的出招、格擋、閃避與特效敘述；柳東蘆（封山劍法）的敘述不收。

標記說明：
- `〔對手〕`＝被攻擊的人（影片中是柳東蘆）；`〔部位〕`＝命中部位（頭部、頸部、左肩、右臂、小腹、後心、左腿、右腳…）。
- 「？」＝逐字稿標註字形不確定，待使用者對照舊畫面確認。
- 影片中景愈濤的兵器固定是古岳風刃，下表寫成〔兵器〕。

### 特效招式

**劍領風騷**（傲劍訣極招，先有起手句，再連發數道劍氣；每道劍氣依「德行」換字與顏色）

起手：
> 景愈濤猛然施展傲劍訣中華麗的劍舞「劍領風騷」！

每道劍氣：
> 景愈濤施展傲劍訣中的極招「劍領風騷」『X』，一道Y色的劍氣射向〔對手〕！

| 字 | 劍氣顏色 | 逐字稿用色 |
|----|---------|-----------|
| 禮 | 藍色 | 藍 |
| 武 | 紅色 | 紅 |
| 義 | 紫色 | 紫 |
| 德 | 青色 | 青 |
| 忠 | 綠色 | 綠 |
| 狂 | 金色 | 金（黃） |

- 「劍領」二字紅、「風騷」二字青（影片畫面的色彩；遊戲內用 mudlib 現成 16 色即可）。
- 一次起手後連續發 5～6 道，順序隨機，同一字可重複（影片中 德、義 常連續出現）。

**罡氣白光**
> 景愈濤手中古岳風刃發出一陣耀眼的白光，光芒中發出一股強烈的罡氣衝向柳東蘆！

**調息／等待**
> 景愈濤從懷中掏出一粒九轉冰心丹，含入口中吞下。
> 景愈濤伺機而動

## 二、格擋與閃避敘述（景愈濤防禦）

影片中景愈濤被柳東蘆攻擊時的防禦句。格擋（兵器接下攻勢）與閃避（身法避開）分開列。
`〔攻方〕`＝柳東蘆；前半句「某某一招…刺向景愈濤的〔部位〕，」是攻方敘述，這裡只收景愈濤的反應。

### 格擋（手中兵器化解）

| 招式名 | 格擋敘述 | 完整結果（影片原句；後面接通用的命中／卸力句） |
|--------|----------|----------------------------------------------|
| 橫劍破 | 景愈濤將手中古岳風刃一橫，一招「橫劍破」，擋住了〔攻方〕的攻勢 | 擋住後，攻勢仍可能帶傷：「怎料…這招來得太快，結果只是輕輕地刺破景愈濤的皮肉」 |
| 天始一乾景初開 | 景愈濤將手中古岳風刃一展，一式「天始一乾景初開」將〔攻方〕的攻勢化開 | 「但只卸去了…部分勁道，結果在景愈濤〔部位〕劃出一道細長的血痕」 |
| 輕柔小扇撲流螢 | 景愈濤將手中古岳風刃一揮（或「一挑」），使出一式「輕柔小扇撲流螢」將〔攻方〕的攻勢化解掉 | 同上，可接「不料…力道實在兇猛」 |
| 不識江山多嬌媚 | 景愈濤身體有如陀螺急轉，一招「不識江山多嬌媚」將〔攻方〕的所有攻勢帶開 | 同上 |
| 緲盡人世絕惡？意 | 景愈濤手中古岳風刃劍芒大盛，一招「緲盡人世絕惡？意」將〔攻方〕的攻勢完全封住 | 完全封住時通常無後續受傷句（偶有「不料…這一擊來得太快」） |

> 「緲盡人世絕惡？意」的「惡」字影片中字形不確定（轉寫者標「?」），請使用者對照原畫面確認。

### 閃避（身法避開，不接兵器）

| 招式名 | 閃避敘述 |
|--------|----------|
| 起落猶立草上尖 | 只見景愈濤一招「起落猶立草上尖」身形突然一淡，閃過了攻擊 |
| 風嘯弱空星追月 | 景愈濤身影迅速晃動，殘影變得無法捉摸，一招「風嘯弱空星追月」輕鬆地閃過 |
| 佳人在擁醉臥君（閃避版） | 景愈濤身子一沉「佳人在擁醉臥君」使出，似酒醉一般，在不可思議的角度閃過了攻擊 |

（「佳人在擁醉臥君」同時是出招 #6，也是閃避招，影片兩種用法都有。）

### 格擋結果的通用句（出現在格擋句之後，非景愈濤獨有，可由戰鬥系統處理）

- 完全擋下：接在格擋句後即結束。
- 卸力不全：「但只卸去了柳東蘆部分勁道，結果…」
- 對手更快：「怎料柳東蘆這招來得太快，結果…」「不料柳東蘆這一擊來得太快」
- 對手更猛：「不料柳東蘆力道實在兇猛，結果…」
- 傷勢：「輕輕地刺破景愈濤的皮肉」「在景愈濤〔部位〕刺出一個創口」「劃出一道細長的血痕」「『噗』地一聲刺入了景愈濤腰間寸許！」
