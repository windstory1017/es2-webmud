# 孟家【五虎斷門刀】設計草案

**建立日期：2026-11-14**　**狀態：設計草案，待使用者確認；確認前不寫程式。**
**依據**：使用者 2026-11-14 的指示「幫孟家兩位武者設計五虎斷門刀，5 個招式敘述都要算狠的，另有一招絕招 delay 對手 3 tick，就叫『五 虎 斷 門』，該招敘述整段黃色，前後空一行」。
**用途**：孟家莊兩位武者的家傳刀法——**孟驚鴻**（「出塵刀」，二莊主）、**孟昭展**（「多情刀」，莊主）。五虎斷門刀由孟家莊開山祖師、天朝開國將軍孟翔溪所創（見 `docs/AREA_FENGCHENG.md` 之後的孟家莊文件）。
**敘述風格**：先看 `武俠敘述風格指南.md`；刀法動詞用劈、砍、斫、斬、截、掃、撩、剁；孟家是軍旅出身的霸道刀法，取黃易、臥龍生的重刀與直白有力，不寫花巧。

標記：未標記＝使用者已指示；【暫定】＝Claude 推演、待使用者確認；【待決定】＝需要使用者決定。

## 一、基本資料

| 項目 | 內容 |
|---|---|
| 名稱 | 五虎斷門刀 |
| 技能代碼 | `five-tiger blade`【暫定】（檔名 `daemon/skill/five-tiger_blade.c`，中文名要加進 `data/chinese.o`） |

| 引擎 | 新版武功引擎 `std/martial_art.c` |

## 二、五個招式（敘述算狠）

`$N` 出招者、`$n` 對手、`$w` 武器、`$l` 部位。一句 25～45 字，用「﹐」切段，結尾不加句號；招名位置輪替（中、中、前、中、中）。
招名都自創，避開虎刀門的瘋虎刀法（餓虎攔路、百獸懾服、風從虎勢等）。

| 招式 | 敘述 | 傷害類型 |
|---|---|---|
| 惡虎剜心 | $N矮身欺近﹐一招「惡虎剜心」﹐$w自肋下反撩而上狠狠剜進$n的$l | 割傷 |
| 伏虎斷腰 | $N腰身猛擰﹐$w橫掃千鈞﹐一招「伏虎斷腰」勢如開山直要將$n的$l一刀兩斷 | 砍傷 |
| 猛虎撲崖 | $N縱身躍起﹐雙手擎$w過頂﹐「猛虎撲崖」挾著千斤力道﹐當頭朝$n的$l狠命劈落 | 砍傷 |
| 飛虎穿林 | $N足尖一點貼地竄出﹐一招「飛虎穿林」﹐$w人刀合一直捅進$n的$l半尺 | 刺傷 |
| 裂爪撕風 | $N左手五指箕張如虎爪﹐右手$w隨後劈落﹐「裂爪撕風」刀爪齊下﹐要把$n的$l撕得皮開肉綻 | 割傷 |

【暫定】招式強度（爆發型、只攻不守，比照瘋虎刀法的方向，數字比照其他 NPC 刀法再微調）：

| 項目 | 數值 |
|---|---|
| 命中（attack） | 6～10 |
| 防守（defense） | 0～3（偏低） |
| 內力加成（force） | 1 |
| 傷害加成 | +10～15% |

## 三、絕招【五 虎 斷 門】

| 項目 | 內容 |
|---|---|
| 名稱 | 五 虎 斷 門（字與字之間有空格，同瘋虎功的「瘋 虎 強 盛 勢」寫法） |
| 效果 | **成功時，對手 delay 3 tick**（`victim->start_busy(3)`；1 tick ≈ 2 秒，使用者指示） |
| 敘述格式 | **整段黃色，前後各空一行** |
| 指令【暫定】 | `perform blade:door-break`（代號待確認） |

### 敘述草稿（整段一行不斷行，黃色 `HIY`）

【待決定：黃色用亮黃 `HIY` 還是暗黃 `YEL`？草稿用 `HIY`。】

成功（前後空一行）：

```

$N一聲暴喝﹐$w幻出五道刀影宛如五隻猛虎出柙﹐自上下左右四面八方同時撲向$n﹐正是孟家祖傳絕學「五 虎 斷 門」﹐刀風過處門戶盡斷﹐$n四面皆是刀光﹐退路被封得死死的﹐一時動彈不得

```

失敗（$n 破解，沒有 delay；同樣整段黃色、前後空一行）：

```

$N一聲暴喝﹐$w幻出五道刀影撲向$n﹐使出「五 虎 斷 門」﹐$n拼著受傷硬生生從刀影裡闖了出去﹐五虎斷門未能封住退路

```

條件不足（精氣神不足、冷卻中）：`你的氣力不足﹐施展不出「五 虎 斷 門」。`（只有出招者看到）

### 規則【暫定】

| 項目 | 草案 |
|---|---|
| 成功率 | 刀法等級 ÷ 4 ＋ 悟性，最高 95%（同玄天劍訣困天訣的算法） |
| 消耗 | 氣最大值的 1/10；自身停頓 1 tick |
| 冷卻 | 6 tick（和傲劍訣的劍領風騷同） |
| 對 NPC 與玩家 | 都生效；對玩家 delay 3 tick，不分職業 |

## 四、NPC 怎麼用絕招【待決定】

孟驚鴻、孟昭展是 NPC，不會自己下 `perform` 指令。有兩種做法：

| 做法 | 內容 | 要改的檔案 |
|---|---|---|
| A（建議） | 技能檔提供「NPC 戰鬥中自動施展」的函式，由 NPC 檔在戰鬥中定時呼叫；絕招冷卻好了就用，成功率同上 | 只改孟驚鴻、孟昭展自己的 NPC 檔和技能檔 |
| B | 用現有戰鬥系統對 NPC 自動使用 perform 的機制 | 目前沒有查到現成機制，需要改戰鬥程式，**要先問使用者** |

## 五、NPC 的武功配置【待決定】

- 孟驚鴻、孟昭展現在只有 `set_power`，武功等級靠 `daemon/misc/npc_skill.c` 依門派自動配置；孟家沒有門派記號。
- 要讓他們自動會五虎斷門刀，有兩個做法：
  - A：NPC 檔直接 `set_skill("five-tiger blade", 等級)` 並 enable（只改 NPC 檔，不動系統面）。
  - B：在 `npc_skill.c` 新增孟家的門派配置（改系統檔，**要先問使用者**）。
  - 建議 A。等級建議 100 級（35 級 A 強度的 NPC，比照其他 NPC 刀法）。
