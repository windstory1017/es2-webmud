## 〇、原版說明（使用者提供）

> 丹道【黃白之術】(alchemy-wealth)
> 學習條件：任務達成後習得
> 任務起始：江述仁
> 特殊能力：gold_seal／silver_seal：金銀咒並沒有本質區別，都是用以將物品轉換為金錢並直接存入錢莊。轉化 500 文以下的物品並沒有等級區別，500 文以上的物品需要技能等級大於物品價格除以 10000（文）才有效。每次使用消耗 15 點的 sen。
> 相關參考：help alchemy-wealth

本設計依使用者決定修改了原版的部分規則（金咒 80 級才領悟、金咒不限價值等），以下各章為準。

**2026-11-14 修改**：80 級卡住並領悟金咒、累積到 100 級門檻直接升到 100；銀咒上限改為一次轉換總額 2000 文；可一次轉多個（on 數量／all）；換錢比例改為 60%～200%（整數）；二階丹藥 × 2、一階丹藥 × 10；成功訊息不顯示存入金額。

## 二、銀咒與金咒

### 2.1 咒的種類

| 咒 | 指令 | 顯示名稱 | 可轉化的物品 | 可用等級 |
|---|---|---|---|---|
| 銀咒 | `conjure silver seal on [數量\|all] <物品>` | 銀咒 | 一次轉換的價值總和 **2000 文以下** | 0 級起 |
| 金咒 | `conjure gold seal on [數量\|all] <物品>` | 金咒 | **任何價值**（不限技能等級） | **80 級領悟後** |

| 編號 | 規則 |
|---|---|
| W-01 | 80 級以前只有銀咒；80 級領悟金咒後才能使用金咒（2026-11-14 由 90 級改為 80 級） |
| W-02 | 金咒可用在任何價值的物品上，包括銀咒轉得動的物品；取消原版「技能等級 ＞ 物品價格 ÷ 10,000」的限制 |
| W-03 | 銀咒的上限是**一次轉換的物品價值總和** ≦ 2000 文（含 2000）。總和超過就整批拒絕，玩家要自己把數量調到 2000 文以內才能轉（2026-11-14 修改；原為單件價值 ≦ 500 文，2026-11-08 #41） |
| W-04 | 物品價值以物品本身的價值計算 【實作注意】使用者稱 base_value；實作時核對各類物品取價值的方式（`value()`、`query("value")`、成丹的 `base_value`），以一般商店計價所用的值為準 |

### 2.2 施法對象

| 編號 | 規則 |
|---|---|
| W-10 | 只能對**自己身上**的物品施法；地上的東西不能轉 |
| W-11 | 成疊的物品可指定數量（2026-11-14 修改，原為一次只轉一個）：`on <物品>` 轉 1 個；`on 20 <物品>` 轉 20 個；`on all <物品>` 轉身上那一疊的全部。指定的數量超過身上有的，顯示「你身上的松柴沒有那麼多根。」，不扣神 |
| W-12 | 不能疊的物品（例如兵器、衣服）一律只轉一件，即使用 `all` 或指定數量也一樣（2026-11-14） |
| W-13 | 一次轉多個時：整批只擲一次成功率、只扣一次神；成功全部轉掉，失敗全部留在身上；經驗以整批物品價值總和算一次（2026-11-14） |
| W-14 | 【實作】數量由 `cmds/std/conjure.c` 解析：`on` 後面找不到物品時，才把開頭的數字或 `all` 當成數量，記在 `conjure/amount`（-1 表示全部）交給法術，施法後清掉；其他法術不受影響 |

### 2.3 不能轉的物品（直接拒絕：不扣神、不給經驗、不加分）

| # | 不能轉的東西 |
|---|---|
| a | 錢（銅板、碎銀、黃金等貨幣） |
| b | 價值 0 的物品 |
| c | 正在穿戴、拿在手上的裝備 |
| d | **凡是能裝東西的容器**，不論裡面有沒有東西：袋子、丹爐、丹鼎、水袋等 |
| e | 人物、NPC、屍體 |
| f | 設定為不能賣、不能丟的物品（例如任務物品）。丹藥只設當鋪不收（`no_pawn`），不屬此類，可以轉化（2026-11-07，見煉丹流程 T-37） |
| g | 地上的東西 |

拒絕訊息（只有施法者看得到）：「你所施用的銀咒，不可施用在這件物品上。」（用金咒時為「金咒」）

### 2.4 銀咒轉不動（直接拒絕：不扣神、不給經驗、不加分）

用銀咒一次轉換的價值總和超過 2000 文時直接拒絕：

- 只轉一件：「你所施展的銀咒，不足以轉化這把神農匕。」（「把」依物品的量詞、「神農匕」依物品名稱替換，例如「這件布衣」「這個葫蘆」）
- 一次轉多個：「你所施展的銀咒，不足以一次轉化這麼多松柴。」

### 2.5 消耗、成功率、失敗

| 編號 | 規則 |
|---|---|
| W-20 | 每次施法固定消耗 **15 點神**；失敗一樣扣；一次轉多個也只扣一次 |
| W-21 | 神不足 15 時不能施法，不扣神、不給經驗 |
| W-22 | 成功率＝**50% ＋ 技能等級 ÷ 2**，**最高 100%**（100 級達到上限）。學成前（0 級）50%、剛學成（20 級）60%（2026-11-15 使用者決定；原為等級 ÷ 4 ＋ 50%，最高 95%） |
| W-23 | 失敗時物品**留在身上**，可以再試 |
| W-24 | 施法後**沒有忙碌時間** |
| W-25 | 尚未領悟金咒就施金咒：顯示「你尚未領悟金咒。」（不扣神、不給經驗） |

成功率範例：

| 等級 | 成功率 |
|---:|---:|
| 0（學成前） | 50% |
| 20（剛學成） | 60% |
| 50 | 75% |
| 80（領悟金咒） | 90% |
| 100 以上 | 100% |

【實作注意】成功率以萬分之一或小數計算，避免整數除法誤差（例如 79 級為 89.5%）。技能等級用原生等級 `query_skill("alchemy-wealth", 1)`。

### 2.6 換錢比例

存入錢莊的金額＝整批物品價值總和 × 比例（技能原生等級）× 丹藥加成（見 2.7）。2026-11-14 修改，比例一律為整數，**不設上限**：

- 學成前（0 級）：60%
- 學成（20 級）：70%，之後每 5 級 ＋1%，到 80 級為 82%
- 從 80 突破到 100 級：100%（突破時一口氣 ＋18%）
- 100 級以後：每級 ＋1%，到 200 級為 200%（比例＝等級）
- 2026-11-14 以前已在 90～99 級的舊角色照 82% 計算

| 技能等級 | 一般物品、三階丹藥 | 二階丹藥（× 2） | 一階丹藥（× 10） |
|---|---:|---:|---:|
| 學成前（0 級） | 60% | 120% | 600% |
| 20（學成） | 70% | 140% | 700% |
| 50 | 76% | 152% | 760% |
| 80（領悟金咒） | 82% | 164% | 820% |
| 100（突破） | 100% | 200% | 1000% |
| 120 | 120% | 240% | 1200% |
| 150 | 150% | 300% | 1500% |
| 180 | 180% | 360% | 1800% |
| 200 | 200% | 400% | 2000% |

【注意】一般物品 101 級起比例超過 100%，而 NPC 商店照物品價值的 100% 販售，玩家可買來轉錢小賺。使用者 2026-11-14 決定接受、不設上限。

### 2.7 丹藥加成（2026-11-14）

| 編號 | 規則 |
|---|---|
| W-35 | 用黃白之術轉換丹藥時，依成品檔 `pill_grade`：**二階 × 2**、**一階 × 10**；三階不加成。只有黃白之術轉換時加倍，丹藥本身的價值、藥鋪售價與收購價都不變 |
| W-36 | 目前一階：大還丹。二階：小還丹、醒神丹、清腹丹、金鎖固精丸、養心丹、甘靈清毒丹（2026-11-14 由三階改為二階）。三階：烏心丹、金液丹 |
| W-37 | 藥鋪櫃台不再販售大還丹（2026-11-14），避免買來轉錢；收購與大還丹配方照舊。二階丹藥最高 400%，低於櫃台售價（成品價值 × 10），沒有轉賣價差 |

| 編號 | 規則 |
|---|---|
| W-30 | 錢直接加到角色身上的錢莊存款（`bank_account`，單位：文） |
| W-31 | 金額計算無條件捨去到文；價值很低的物品可能換到 0 文（例如價值 1 文 × 60%），仍算成功 |
| W-32 | 成功訊息不顯示存入金額（2026-11-14）；要看存款到錢莊查 |

## 三、技能提升

| 編號 | 規則 |
|---|---|
| U-01 | 向江述仁學，最多學到經驗值 50（見第一章） |
| U-02 | 學會後靠施展銀咒、金咒提升 |
| U-03 | 施法成功：獲得「**物品價值 ÷ 100**」（一次轉多個時用整批物品價值總和，算一次，2026-11-14）與「**random(靈性 ＋ 悟性)**」兩者**取大的**點數。「物品價值 ÷ 100」每次最多 **技能等級 × 100** 點，**0 級（學成前）不設上限**（2026-11-07 使用者決定：原本只給「價值 ÷ 100」，轉便宜物品時成功反而比失敗少；同日稍早曾定為兩者相加，後改為取大） |
| U-04 | 施法失敗：獲得 **random(靈性 ＋ 悟性) ÷ 2** 點經驗（無條件捨去；2026-11-07 使用者決定由 random(靈性 ＋ 悟性) 減半） |
| U-05 | 神不足、不能轉的物品、銀咒轉不動、尚未領悟金咒：不給經驗 |
| U-06 | 1～19 級不會出現：經驗累積到學成門檻後，直接學成 20 級，顯示：「你因為長期使用丹道【黃白之術】，所以你對這個法術已經逐漸熟悉。」 |
| U-07 | **2026-11-14 修改**：升到 80 級時領悟金咒，顯示：「由於你長期使用丹道【黃白之術】，使你對丹道【黃白之術】更加的熟悉，並領悟金咒。」。80 級後不再升級，只累積經驗；經驗達到 100 級的累計值時，直接從 80 升到 100，顯示：「你對丹道【黃白之術】的體悟豁然貫通，點金化銀的功夫更上一層樓。」。原為 79 級卡住、直接升 90 並領悟金咒。已在 90～99 級的舊角色維持原等級。**2026-11-04 修正（#31）**：技能檔以 `query_learn_at_cap` 表明卡住的等級照常累積經驗，系統 `feature/char/skill.c` 認得這個例外 |
| U-08 | 20～80 級、100 級以後照一般技能規則升級（見 3.1） |
| U-10 | 每次施法增加**丹道修養**（`alchemy`）：成功 ＋（1 ＋ random(黃白之術等級) ÷ 2，無條件捨去），失敗固定 ＋1（與神農之術相同）；U-05 各情況不加 |
| U-12 | 系統規則：<br>A. 施法成功時，法術修為、丹道修養各 ＋ random(靈性 ÷ 6) ＋ 1（`cmds/std/conjure.c`）。U-10 的丹道修養另外照給。<br>B. 升到第 n 級時給 n × 10 法術道行（`feature/char/skill.c`）。<br>法術修為、法術道行**不另外給**（使用者原設計「每級（等級−1）×10 法術修為、超過 31 級另給（等級−30）×10 法術道行」已取消） |
| U-13 | 施法時同時累積**基本法術**（`magic`）經驗（2026-10-24，使用者指示 #12）：照茅山法術的基本法術公式，層級固定 1：（random(靈性)＋1）×（random(靈性)＋1）＋random(靈性)。施法失敗（會扣神的失敗）時取 1/3，無條件捨去，最少 1；直接拒絕、不扣神的情況不給。以 `improve_skill_exact` 給，不吃人物等級加成；只給玩家 |

【實作注意】U-10 在 0 級時避開 random(0)：0 級成功固定 ＋1。`random(n)` 為 0 到 n−1。

【實作注意】系統規則 A 目前在施法失敗時也會加分；使用者決定修正為只有真的施法成功才加分（改 `conjure.c`，所有職業的法術都適用）。實作前先查清楚各法術技能如何回報成功、失敗，向使用者說明影響範圍。

### 3.1 各等級累積經驗（系統預設門檻）

升到第 N 級所需累積經驗＝N² × 基數（`feature/char/skill.c`；基數 60 級以下 100、61～90 為 125、91～120 為 150、121～160 為 175、161～180 為 200、181 以上 250）。

| 等級 | 累積經驗 |
|---|---:|
| 20（學成） | 40,000 |
| 50 | 250,000 |
| 80（領悟金咒） | 800,000 |
| 100（從 80 直接升上來） | 1,500,000 |
| 120 | 2,160,000 |
| 180 | 6,480,000 |
| 200 | 10,000,000 |

### 3.2 練功量參考【推算】

| 階段 | 每次成功最多得到 | 說明 |
|---|---|---|
| 0 級（學成前） | random(靈性＋悟性) | 只能用銀咒，一次總額最高 2000 文，價值 ÷ 100 最多 20 點，多半是 random(靈性＋悟性) 較大 |
| 20～80 級 | random(靈性＋悟性) 或 20 點 | 同上；經驗上限（2,000～8,000）用不到 |
| 80 級以後 | 技能等級 × 100 | 金咒可轉任何價值；轉貴重物品時「價值 ÷ 100」較大，物品價值達「等級 × 10,000 文」就拿滿上限 |

以靈性 17、悟性 13 為例，random(靈性＋悟性) 平均約 15 點，80 級前每次成功約 15～20 點：學成 20 級約需成功 2,000～2,700 次；練到 80 級（80 萬點）約需成功 4～5.3 萬次（以上為 2026-11-14 前的估算方式，未重算一次轉多個的影響）。失敗是 random(靈性＋悟性) ÷ 2，平均約 7 點，所以成功一定不少於失敗（2026-11-07 調整；原本每次成功只有價值 ÷ 100，轉便宜物品時比失敗少）。

## 四、玩家訊息

自己看到的「你」依性別顯示「你／妳」。「銀咒」依實際施展換成「金咒」；「神農匕」依物品名稱替換。

| 情境 | 誰看得到 | 訊息 |
|---|---|---|
| 施法 | 自己 | 你手捏法訣，對著神農匕唸動「銀咒」。 |
| 施法 | 旁人 | $N手捏法訣，對著神農匕唸動「銀咒」。 |
| 成功 | 只有自己 | 神農匕化作一道銀光，消失無蹤。（金咒為「金光」；2026-11-14 起不顯示存入金額）<br>一次轉多個：二十根松柴化作一道銀光，消失無蹤。 |
| 成功 | 旁人 | 不顯示（旁人只看得到施法過程） |
| 失敗 | 自己 | 你的法術失敗了。 |
| 神不足 | 自己 | 你的「神」不足以施展這個法術。 |
| 不能轉的物品 | 只有自己 | 你所施用的銀咒，不可施用在這件物品上。 |
| 銀咒轉不動 | 自己 | 你所施展的銀咒，不足以轉化這把神農匕。<br>一次轉多個：你所施展的銀咒，不足以一次轉化這麼多松柴。 |
| 數量不夠 | 自己 | 你身上的松柴沒有那麼多根。 |
