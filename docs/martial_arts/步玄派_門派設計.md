## 一、門派背景（照現有資料整理）

- **所在地**：落雲峰上（`d/swaylan/buxuan/`），自給自足、耕讀習武，「武功自帶書卷氣」（設計表）。
  已有房間：步玄派大門、石階、平台、聚雲池、農田、小茅屋、沐華居等。
- **始祖駱步玄**：
  - 沐華居廳堂掛著他的字畫，畫的是「一頭顧盼生威的大鷹」。
  - 七十歲時在練火大山的無名山谷，誤闖風神族的聚會，跟風神族英雄「夜鷹」比輕功，
    以一步之差贏得風泉之劍。
  - 他把「創步玄功」「得風泉劍」「娶吾賢妻」當成平生三大樂事。
  - 也就是說，步玄派的根本是**輕功（步法）**，連傳家寶劍都是用輕功贏來的。
- **掌門駱易**（`custom/legacy_npc/ro_yi.c`，已在沐華居）：
  - 性格恬淡、謙退自抑。
  - 少年時孤身闖入飛狼城，救回當今皇帝與香雪王，之後辭官，隱居在喬陰祖宅。
  - 身上帶著兩把劍（落雲刃、逐風刃，逐風刃還沒做），符合「步玄派可使雙劍」的說法。
- **門下**：步玄派弟子（腰佩長短兩劍）、農夫。
- **門外與步玄派有關的人**：
  - 歐陽芝：大漠八魔之一，「武功似乎是步玄派的」，算是旁支或叛徒，之後可以當成劇情線索。
  - 駱雲峰（駱老三）：同樣姓駱，住在落雲峰，教的雲峰筆招是**共通武功**，不屬於步玄派。

## 二、三套門派武功（名稱照遊戲對照檔）

| 武功 | 代碼 | 種類 | 舊資料記載 |
|---|---|---|---|
| 步玄心法 | `myst-force` | 內功 | 練滿時「大吼一聲」，全服都看得到。居士進階後多了乾坤三轉 |
| 步玄七絕 | `myst-steps` | 閃躲 | 「冠絕天下的獨門輕功」。逍遙遊：120 級後，視悟性高低有機會恢復精、氣，同時躲閃能力變成四倍 |
| 小步玄劍 | `close myst-sword` | 劍術（可用雙劍） | 「可使雙劍，皆可 enable 小步玄劍」。格擋時恢復精氣（2012-09-29 改為加倍） |

評等（玩家簡介，居士步玄）：攻擊 B、防禦 B、**續戰 S**、靈活 B。
整個門派的方向是**靠身法閃、靠格擋回、越打越耐**，爆發要等進階才有（奇門劍訣）。

## 三、各武功的提案（待確認）

數字都是我先填的建議，等你看過再改。

### 1. 小步玄劍（close myst-sword）

| 項目 | 提案 |
|---|---|
| 可 enable | 劍術（sword）、左手劍術（secondhand sword）、招架（parry） |
| 學習 | 拜師後即可習得 |
| 練成 | 20 級（比照冷梅劍法、封山劍法） |
| 定位 | 「小」字取近身短打之意：劍招短促精巧、守多於攻。數值落在命中略低、防守偏高，傷害加成低 |
| 特殊能力 | **招架回氣**：以小步玄劍招架成功時，有機會回復精、氣（2012 年公告的「格擋恢復精氣」）。數值待定 |
| 招式 | 七招左右，敘述帶書卷氣與鷹的意象（俯衝、盤旋、收翅）；等方向確認後再寫，寫前會先看《武俠敘述風格指南》 |

### 2. 步玄七絕（myst-steps）

| 項目 | 提案 |
|---|---|
| 可 enable | 閃躲（dodge） |
| 學習 | 拜師後即可習得 |
| 練成 | 10 級（比照狻猊步法、倒亂七星步法） |
| 閃避敘述 | 「七絕」正好七式；以駱步玄與夜鷹比輕功、大鷹字畫為意象（鷹揚、乘風、一步之差） |
| 特殊能力 | **逍遙遊**：步玄七絕 120 起，被攻擊時有機會發動，機率看悟性。發動時回復精、氣的現在值，這一招的閃躲能力變成四倍 |

- 舊資料寫「120 級後」，沒說是人物等級還是步玄七絕的等級。依其他門派的寫法，我先用**步玄七絕 120**（待確認 #3）。
- 遊戲對玩家只說「步玄七絕已臻化境」這類話，不提數字。

### 3. 步玄心法（myst-force）

| 項目 | 提案 |
|---|---|
| 學習 | 人物等級 5（比照玄天心法，門派武功對照表裡書生內功是 5 級） |
| 練成 | 照一般內功門檻 |
| 功能 | refresh（運氣回精）、heal（療傷）兩項基本功能 |
| **大成公告** | 練滿時全服公告（走新的 event 頻道，玩家可以用 tune 關掉）。敘述草稿：「落雲峰上傳來一聲清越長嘯，聲震四野，久久不絕——$N的步玄心法終於大成了！」 |
| 能力提昇 | 每級精、氣上限增加；大成時再給一次屬性（待定，建議悟性、機敏方向，符合書生與輕功） |

- 「練滿」是指 100 級還是 200 級，舊資料沒寫（待確認 #4）。

### 先不做：書生共用進階（四廠、居士）

簡介裡的「奇門劍訣」（四廠：步玄七絕累積七點後發動，次數看五行陰陽之學、威力看古文造詣、
機率看悟性）與「乾坤三轉」（居士：步玄心法耗神回精氣，下一招必出奇門劍訣），
都是**書生進階**後才有的能力。進階屬於職業系統，不在這次門派範圍內；
等進階制度做好，再回來替步玄派接上這兩項。

## 四、需要改到系統面的地方（要先經你同意）

照工作規則，下列不是武功檔本身，需要你點頭才動：

1. **駱易收徒、傳授**：在 `ro_yi.c` 加拜師（apprentice）與傳授（acquire）。這是改 NPC。
2. **門派 NPC 自動武功**：在 `daemon/misc/npc_skill.c` 的門派表加 `scholar.myst`，
   這樣駱易和步玄派弟子打架時才會用步玄派武功。
3. **門派武功對照表**（`門派武功對照表.md`）：加上步玄派這一列。這份是你提供的表，要不要由我補上？
4. `ro_yi.c` 開頭的註解還寫著「尚未放入地圖」，實際已經在沐華居，順手更正。

## 待確認

1. **拜師條件**：種族、性別要不要限制？簡介推薦人類、夜叉，但沒說不收其他種族。我建議不限，只要是平民，
   也許再加「讀書識字要有點根基」來表現書卷氣。
2. **小步玄劍可 enable 在招架嗎？** 舊資料寫「格擋恢復精氣」，表示應該可以。
3. **逍遙遊的「120 級」**：指步玄七絕 120 還是人物等級 120？
4. **步玄心法的「練滿」**：100 級還是 200 級？大成公告要不要做？
5. **有沒有步玄派的對戰紀錄或舊版招式名稱？** 像封山派那樣有紀錄最好；沒有的話招式、閃避敘述就由我新寫。
6. **第二節的整體方向**（閃避＋招架回復、續戰為主、爆發留給進階）可以嗎？
