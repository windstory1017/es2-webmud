| 特色 | 落在規則上 |
|---|---|
| 瑯夷派走暗殺、偷襲路線（`瑯夷派_瑯夷派內功.md`） | 步法本身提供閃躲，招牌是「脫離戰鬥」 |

## 閃避敘述（草稿，$N 出招的人、$n 閃避的人）

只有真的閃過時，才接在對方出招敘述後面。無招名，靠輕盈的蝶意象；一句最多兩個標點。

1. $n身子輕輕一飄﹐像蝶翼振了一下﹐讓$N撲了個空
2. $n足尖一點﹐順著勁風向旁滑開﹐$N的攻勢擦身而過
3. $n腰身一折﹐貼著地面斜掠出去﹐避開了這招
4. $n左一晃右一閃﹐幾個折步之間已繞出丈許﹐$N只抓到一片衣角
5. $n翩然往後掠起﹐落地時悄無聲息﹐這一招落了個空
6. $n身形一虛一實﹐留下一道淡淡的殘影﹐真身卻已站在$N的側面

## 練成敘述（草稿）

> 你終於練成了蝶影幻步﹐身子輕得像一片羽翼﹐一個起落已飄出數尺。

## 特殊能力：脫離戰鬥（草案，核心）

做法比照現成的茅山鬼煙術（`daemon/skill/taoism_of_darkness.c` 的 `do_smoke`）：**只在技能檔裡**呼叫現有的
「解除雙方殺意」與「暫時隱藏」，不需要改戰鬥系統。

| 項目 | 草案 |
|---|---|
| 使用時機 | 正在戰鬥中才能用；沒有交手時說「用不著脫身」 |
| 解鎖 | 蝶影幻步 **30 級**起（程式內部條件，敘述不提等級）；火候不足時說「你的蝶影幻步火候未到，還無法脫身。」 |
| 效果 | 自己與所有對手互相解除殺意，離開戰圈；同時隱藏，隱藏值 1 + random((潛行 + 蝶影幻步) ÷ 2 × 2)（比照鬼煙術） |
| 看不穿的對手 | 失去你的蹤影，不再追擊 |
| 看得穿的對手 | 只停手一次，之後可以重新出手（比照鬼煙術） |
| 成功率 | 預設**一定成功**（舊文章說「非常好用」）；若覺得太強，改為看自己的蝶影幻步與對手行動力比較（待確認，問題 2） |
| 消耗 | 氣目前值 1/5；氣不到 1/3 不能用（比照殘煙的限制） |
| 使用後 | 自己停頓 2 回合（使用者可調），不能連續脫身 |
| 限制 | 被定身、動彈不得（busy）時不能用 |

敘述（草稿，沿用瑯夷派的暗色調）：

| 時機 | 敘述 |
|---|---|
| 不在戰鬥 | 你並未與人交手﹐用不著脫身。 |
| 火候不足 | 你的蝶影幻步火候未到﹐還無法脫身。 |
| 氣不足 | 你氣血虛浮﹐提不起勁施展身法。 |
| 施展 | $N足下一點﹐身形忽左忽右﹐宛如蝶舞花叢﹐幾個起落已掠出戰圈。 |
| 旁人看到（看不穿） | 眾人眼前一花﹐已不見$N的蹤影。 |
| 看穿的對手 | $n目光一轉﹐牢牢盯住了$N的去向。 |
| 自己 | 你藉著蝶影般的身法掠出戰圈﹐悄悄隱入暗處。 |

## 取得方式的草案（待確認）

方案 A（建議）：**葉翔的任務**。
- 理由：舊資料 `葉翔 drinkblood 任務`（`REFERENCE_BOARD_2007_2013.md:399`）與蝶影幻步同列為五堂鎮任務；葉翔本來就是輕功一絕的角色，佔位已設蝶影幻步。
- 做法：瑯夷派弟子才聽得進葉翔的話；任務流程另外討論，確認後再寫成 `docs/AREA_WUTANG.md` 的任務段。

方案 B：吳長貴直接教（最簡單，但和「每門只教入門」的定案不合）。

## 需要使用者決定的問題

1. 取得方式：方案 A（葉翔任務）還是方案 B（吳長貴教）？A 的任務流程要怎麼設計？
2. 脫離戰鬥要不要一定成功？還是看蝶影幻步與對手的行動力比較？
3. 脫離戰鬥的解鎖要多高、消耗與停頓是否照草案？
4. 要不要順便讓蝶影幻步提高其他暗殺技能（例如潛行）？舊資料沒有說，草案是**不給**，避免和瑯夷派內功重疊。
5. 葉翔現在是 110 級佔位 NPC；要不要之後讓他真的施展蝶影幻步（NPC 武功設定屬於 `daemon/misc/npc_skill.c`，要改的話需另外同意）。
