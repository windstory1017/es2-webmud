# 水嵐縣（d/swaylan）設計文件

依使用者提供的水嵐縣設計表（Excel，2026-10-30）整理。全區約 100 間房、35 種 NPC，分五批製作。
每一批都是：先把房間與 NPC 敘述列給使用者確認 → 確認後寫程式 → 開 PR。

目前狀態：**第一批（水嵐縣城）、第二批（冷梅莊）已製作完成**；第三～五批尚未開始。

- 出口：south 北城門
- 功能／NPC：安全區；渡船之後做

> 羿水流到這裡轉了一個大彎，河面寬闊，對岸五堂鎮的鯉君渡隱約可見。岸邊用粗木樁搭起一座棧橋，橋板被往來的腳步踩得發亮，繫船的麻繩一圈圈纏在樁上，河水拍著樁腳，嘩嘩作響。

- 來源：新寫

> 水嵐縣的北城門正對著羿水，城樓不高，門洞卻砌得厚實，幾名守衛持著兵器分立兩旁，盤查進出的行人。城門東首緊挨著一段年久失修的舊牆，牆根坍出一個半人高的破洞，洞後隱約是一片荒廢的院落。
