## 二、繡花流程

玩家對白甌說話（`say` 內容含「繡花」）觸發。進度每位玩家各自獨立，記在白甌身上
（白甌被殺或重開即消失，不補償）。

**顯示格式（使用者指示，2026-11-13）**：白甌說的話一律照 `say` 的格式「白甌說道﹕」加綠色內容
（`HIG`）；動作描述用表情的青色（`CYN`）。下面 `「…」` 內是綠色的話，`〔…〕` 是青色的動作。

1. **邀請**
   > 〔白甌擱下手中的繡繃，抬眸淡淡一笑。〕
   > 白甌說道﹕「繡花麼？也罷，難得有人識貨。取五兩黃金作工錢 (give 5 gold to bai ou)，再備一件素淨的布衣
   > (give cloth to bai ou)，我替你繡上幾針。記著，先付工錢，後交衣裳，這是我的規矩。」
2. **工錢不足（低於 50000 文）**：不收，錢退回。
   > 白甌輕輕搖頭說道﹕「我這一針一線，可不是尋常價錢。五兩黃金，少一文也不成。」
3. **工錢足額（含超過，不找錢）**：收下，記為已付。分次給不累計。
   > 白甌笑著說道﹕「衣裳呢？取來讓我瞧瞧」
4. **未付工錢就先給布衣**：不說話，衣裳退回。
   > 〔白甌愉快地對著你微笑著。〕
5. **給了別的東西／別種衣服／已繡過的衣服**：不收。
   > 白甌說道﹕「我的針只為布衣 (cloth) 而動，這東西，恕我不繡。」
   > 白甌蹙眉說道﹕「這件已有人下過針了，我不願在別人的針腳上再添一筆。」
6. **已付工錢又給錢**：不收。
   > 白甌搖頭說道﹕「工錢你已經付過了，不必再給。把布衣拿來吧 (give cloth to bai ou)。」
7. **開始（收到布衣）**：原布衣銷毀（give 收下有價值的物品會自動銷毀）。
   > 〔白甌接過你遞來的布衣，銀針在布面上起落如蝶，轉眼已見雲紋隱隱。〕
8. **完成（1 tick＝2 秒後）**：說一句話並交出新的「繡花布衣」，句子依繡花結果：
   > 白甌說道﹕「成了，〈結果句〉」
   > 白甌交給你一件繡花布衣。

   | 結果 | 結果句 |
   |---|---|
   | 屬性 | 針腳裡藏了幾分靈氣，穿著它，人也精神些。 |
   | 傷害＋攻勢 | 這一路針法帶著鋒芒，出手時自有幾分銳氣。 |
   | 傷害－攻勢 | 今日心緒有些浮，針腳走偏了鋒芒，莫怪於我。 |
   | 防禦＋守勢 | 密針織成屏障，尋常刀兵難近。 |
   | 守勢－ | 針腳鬆了幾分，守勢怕是弱了些，莫怪。 |
   | 詞綴 | 這一路針法難得，是我少有的得意之作。 |
   | 行動力 | 針腳輕靈，穿上它，身形當更見靈動。 |
   | 警覺性 | 我在襟邊暗藏了一線機巧，風吹草動，你自會察覺。 |

- 玩家中途離開：衣服就沒了（使用者決定），〔白甌見人已走遠，輕嘆一聲，將繡好的衣裳收了起來。〕
- 白甌被殺：製作中斷，工錢與布衣都不補。
- 付了工錢還沒交布衣就離開：進度記在白甌身上，回來再交即可；白甌重開機則消失。

## 三、繡花布衣（新物件）

- 檔案：`obj/area/obj/embroidered_cloth.c`，由白甌產生，**不是**原布衣改的；原布衣被白甌收走銷毀。
- 預設名稱「繡花布衣 (Embroidered cloth)」，防禦力 1（同布衣），記號 `embroidered`，
  所以**不能再次繡花**。id：`embroidered cloth`、`cloth`。
- 每件只擲一次，八種結果互斥（機率合計 100%）：

| 機率 | 結果 |
|---|---|
| 20% | 膂力／膽識／定力／悟性／智慧 擇一（各 1/5）+1~3 |
| 20% | 傷害力 +1~10、攻勢等級 +10~20 |
| 10% | 傷害力 -1~10、攻勢等級 -10~20 |
| 20% | 防禦力 +10~15、守勢等級 +10~20 |
| 10% | 守勢等級 -10~20 |
| 10% | 衣服前綴一個；再 20% 機率加後綴（見第四節） |
| 5% | 行動力 +25~50 |
| 5% | 警覺性 +50~100 |

- 守勢扣到負值：照扣（衣服原本 0，所以會是負的）。
- 價值：布衣 200，詞綴每個修飾 ×1.5（沿用詞綴規則）。
- 存檔：登出照遊戲一般規則，繡花布衣會被丟在地上（使用者決定，2026-11-13），不設 `query_autoload`。
  只有家園儲物箱會保留內容（結果、屬性、詞綴、自取名字）：衣服提供 `query_store_data()` /
  `restore_store_data()`，儲物箱（`custom/home/obj/storage_chest.c`）存取時呼叫。格式
  `1|結果|屬性|前綴|後綴|自取名字`。
- 衣服敘述（look）：「一件經名家之手繡過的布衣，雲紋在衣襟與袖口隱隱流轉。」命名前後相同；
  命名的指令說明放在 `help name`。

## 五、`name` 指令（新增，`cmds/usr/name.c`）

- 格式：`name cloth as <名稱>`；只能用在自己身上的繡花布衣，可重複命名、不收費。
- 長度：最多 12 格（6 個中文字或 12 個英數字），同 `nick`。
- 限制：不可換行或夾控制字元、不可含 `$`、`%`（顏色碼）；每個中文字都必須是 Big5 有的字。
  不擋系統名。
- 命名後：中文名稱改成玩家取的名字，英文維持 `Embroidered cloth`；
  原詞綴名稱被蓋掉，屬性保留。
- Big5 判斷：遊戲內部是 UTF-8，要靠字表。新增 `tools/gen_big5_table.py` 產生
  `daemon/misc/big5_d.c`（由 Python 的 cp950 產生，與 `check_big5_text.py` 同一標準）。
- 說明：`help name` 寫在指令檔內。
