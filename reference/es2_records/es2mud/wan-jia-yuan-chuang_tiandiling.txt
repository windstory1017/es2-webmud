# 天靈地靈任務

天地靈任務其實就是Reset 任務的後續,  可以取得一個eye 和heart, board 2 w post 59有貼, 我只是轉載跟補充, 不過招喚方法早就被zorg改了, 他從不更新的!

- 天靈任務: 很簡單去-赤魈村許願池內丟入任意 3 樣火雷風雨四神的武器 ( 3 個同武器也可以 ) 他就會冒出來說你把水弄髒而pk你!

- 天靈打法: 他會使用隱神篇, 此招是上五雷也沒用的一種特殊武功, 他完全是看你防禦力. 我拿防禦力950的哭笑護法試過, 可以幾乎完全防禦他的任何攻擊, (只是你也知道huge沒攻擊力,所以你也打不死他...take a long time!) 所以打驚異二針霸甲針可以扣除不少它造成的傷害, 然後需要一隻會定住她的, 他會使用一種法術讓人攻勢等級變得很低(即讓你不出招), 所以這邊建議冷梅虎刀配(此乃es2拚秒殺最強組合) 寒霜三千一定,虎刀太守或鬼才都可以,猛砍一輪應該可以直接秒殺ko. 他是神級的所以一樣補4次血.打死可以取得一把跟思歸符效果一樣的dagger, 不必裝備便可以無限使用! 以及eye. eye效果: 吞了隨機提升1點 spi int cps wis 扣另外那四樣, 需要跟heart交替使用.

- 地靈任務: 招喚方法複雜為先取得->聖木殘根(挖混沌珠同一個room wield 穿靈->dig 樹根, 會出現大蜈蚣在後海湖, 打倒後可以取得)->donate 給神廟給太陽鳥一顆大環丹換得金屋內丹-> donate金  屋內丹-> 炎日箭->找太陽狼草擠他的汁成為 太陽槍-> donate pike-> 去地獄黑袍怪人的地氣塔頂insert 開啟天靈.

- 地靈打法: 非常不好對付, 因為該room 既不可以exert, 且不能perform, 只能硬砍他, 他效果跟天靈一樣,同樣補四次血! 聽天由命吧! 打倒後取得axe 跟heart.  heart效果: 吞了隨機提升1點con cor dex str 扣    另外那四樣, 需要跟eye交替使用.

eye 和 heart 隨機扣的屬性如果不足十，會出現使用無效，沒有得到垂青的失敗描述。
