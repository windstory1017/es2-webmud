================================

勾魂鬼(Symbol-ghost of death)

================================

勾魂鬼是人類最熟悉又最不願見到的鬼﹐他們的出現常常代表著死亡。不過實際

上﹐大多數勾魂鬼是很少離開陰間的。

=> 玩家血太少似乎會被直接殺掉

================================

冤魂(Ghost of hate)

================================

因為受到冤屈而死的人的鬼魂不肯投胎四處游蕩。這類鬼很少傷害無辜的

人。但是卻也被下三流的術士們抓住封在塔中﹐可以說是稍有悲劇色彩。

================================

雲外鏡(Ungaikyou)

================================

一個身體若有若無的鬼魂﹐她的臉...好像是面鏡子噢。

================================

淘氣鬼(Poltergeist)

================================

一個小男孩的鬼魂，似乎並沒有意識到自己已經死去了，仍然無懮無慮的在人間玩耍。

=> 淘氣鬼正頑皮的看著你。

================================

六道天女 鳳盈盈(Feng ying ying)

================================

鳳盈盈？茅山派的第四代掌門鳳盈盈？她不是在茅山總壇的那場大火之後不久就已

離開人間了嗎？已是鬼魂的她保留著年輕時的相貌，給人一種古典端莊的美感，一

雙烏黑空洞的眼睛中似乎已看破了歲月的懮傷，但還是在靜靜的期待著甚麼 ...

鳳盈盈舉手投足間神色從容，頗有泰山崩於前面不改色的氣派，她看起來約二

百一十多歲。

鳳盈盈說道；茅山的秘密一定要流傳下去 ...

鳳盈盈說道；茅山派，茅山派會再復興的 ...

================================

狂骨(Kyoukotu)

================================

一具身著白色壽衣的人骨﹐在你週圍飄過來又飄過去...

=> 狂骨告訴你: 我死的好慘啊～～～～ （如果殺業超過兩萬會看到，delay 4

================================

  小雨坊(Kosamebou)

================================

一個長得十分可愛的小孩的鬼魂﹐不知道為甚麼﹐他身上破破爛爛的

衣服總是濕淋淋的。

=> 小雨坊怔怔地對著天空發起呆來。

=> 小雨坊低聲問道: 我的衣服怎麼不會乾呢﹖

================================

  火消婆(Hikesibaba)

================================

一位花白頭髮的老婆婆的鬼魂﹐她身上散發出一股燒焦的味道。

================================

枉死的冤魂(Ghost) ... 羅城

================================

一身素衣的鬼魂。

=> 枉死的冤魂說道﹕我死的....很...慘...啊~~~

=> 枉死的冤魂不停地哭哭啼啼....

================================

小女孩(Ghost child) ... 羅城

================================

一個衣衫襤褸的小女孩，怪可憐的坐在這裡。

=> 小女孩蹲在牆角不停的哭哭啼啼。

================================

李家村長老 李嘉道(Li jia dao)

================================

李嘉道是李家村的長老，也是夜叉族的長輩。很多記憶力不好的夜

叉族人都常常來拜訪他，查詢自己「吞食鬼魂的記錄」。

=> 李嘉道說道: 最近的年輕人啊 ... 唉 ...

=> 李嘉道看著遠方的天空陷入了沉思，慢慢的，睡了過去 ...

你說道﹕吞食鬼魂的記錄

>

李嘉道掃了你一眼，怒道：你這還沒吞過鬼魂的小孩子不要來打擾我。

================================

赤舌(Akasita)

================================

一個飄浮在空中的死人頭﹐碗口大的嘴巴裡伸出一條長長的舌頭﹐

如果被舔到﹐一定很惡心。

================================

否哉(Iyaya)

================================

一個身材誘人的清秀女鬼﹐可是她右臉之上又生一頭﹐狀若豬頭

奇丑無比。

=> 否哉告訴你: 你好帥啊﹐留下來陪奴家吧 ～～～～

================================

  天井嘗(Tennjyouname)

================================

一個跟屋內樑柱一樣高的鬼魂﹐長得也瘦瘦的﹐看起來真的跟柱子差不多。

================================

長壁(Osakabe)

================================

一個飄浮在空中的骨灰盒﹖不僅如此﹐骨灰盒的正面還有一張老人

的臉﹗據說長壁生氣的時候﹐會利用骨灰盒內的骨灰幻化出人的身

體﹗

===================================================

  髮鬼(Kamioni)

===================================================

一個長得十分秀氣的女鬼﹐一頭烏黑的秀髮猶如一條黑蟒 ...

啊﹐她的頭髮真的就是一條黑蟒﹗﹗
