0. help newbie （可能有點舊）

    然後看這一篇（官網）

    https://sites.google.com/site/es2mud/home/wan-jia-yuan-chuang/qanda

 

1. help cmds 基礎指令

   （把所有 cmds 都 help xxx 過一次，可能會花你 2 個小時）

2. help class 門派

   （把所有 class 都 help xxx 過一次，可能會花你 2 個小時）

3. help race 種族

    help race.details

   （把所有 race 都 help xxx 過一次，可能會花你 1 個小時）

4.  接著看一下故事背景   （可能會花你 1 個小時  

  help history

      help myth / myth.1 / myth.2

      help peoples / theme / history.ys / history.zx / history.wz

5. 有空的話，去書局買一本「山海經」白話本來看 （可能會花你 2~4 個小時

     

6. 開始玩之後，pot 附近的所有 board 記得看過，並常 update

7. Annihilator or Zorg  上線時，多注意他們聊天內容。

8. 閒著沒事時，help ALL
