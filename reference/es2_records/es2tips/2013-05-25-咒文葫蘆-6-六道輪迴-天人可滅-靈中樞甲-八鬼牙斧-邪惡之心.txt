和尚繼續說：道兄，就讓我們一起作法為這些亡魂超渡吧。

道士點了點頭，同時布下結界，施展困魂咒以縛眾魂。

和尚把咒文葫蘆的咀蓋掀開，把其中的孤魂野鬼放了出來。

( 一瞬間結界中滿佈了孤魂野鬼, 陰氣瞬間提昇 ... )

道士說道：不好了！陰氣已遠勝陽氣，結界似乎承受不了如此強盛之陰氣 ...

( 結界隨之破除 ... 頃時 ... 強盛之陰氣跟陽氣相沖撞！)

( 陰陽之間的空間扭曲！出現了一道缺口，從人間直達地府十八層！ )

道士說道：糟了 ... 結界破除了，陰陽更失衡 ... 打開了一道通往地府的缺口！

( 聚魂竟被陰間之引力吸了進去 ... )

道士驚惶的叫道：似乎有什麼東西要從地府爬上來！

( 陰氣也慢慢被人間陽氣所中和，陰陽之間的缺口也開始收窄了 ... )

( 但在缺口消失前的那一刻，一頭惡魔竟從缺口中爬了出來！ )

> l ghost

噬魂，嗜吃魂，原是鬼王「顝蛪」一員魔將，論能力比十二鬼將更為強

悍。但當鬼王「顝蛪」被封，噬魂異心即起！自立為鬼王，四處吞噬靈

魂已增其法力。在一次跟地府鬼將的戰鬥中，戰敗被擒，給困在地獄十

八層盡受苦刑。

噬魂長得虎背熊腰，看起來相當孔武有力，他看起來約一千六百六十多歲。

靈中樞甲(Soul lapis lazuli plate)

> l plate

一件湛藍色的寶甲，由無數片青金石以烏金絲線縫合，由內以外共縫合

了五層。仔細的看，可看到每一片青金石上都面雕刻了一個骷髏頭。

> wear plate

你穿上一件靈中樞甲。

> id plate

一件湛藍色的寶甲，由無數片青金石以烏金絲線縫合，由內以外共縫合

了五層。仔細的看，可看到每一片青金石上都面雕刻了一個骷髏頭。

> wield axe

這把八鬼牙斧的重量對你來說有些輕了，使動起來覺得不怎麼實在。

你裝備八鬼牙斧作武器。

> id axe

一把用千歲惡鬼的巨大牙齒製成的斧頭。此斧斧刃上有一層血跡，不知

有多少人被此斧斬殺，斧背上所刻的詛咒符文據說可以封住被殺者的靈

魂，使其永世不得超生。

  雙手斧術 (twohanded axe)
