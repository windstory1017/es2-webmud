# ES2 舊紀錄（第三方整理，僅供參考）

使用者於 2026-11-13 提供，只保留純文字。這些都是玩家或社群整理的第三方資料，**不是官方設定**，
也不是 `source/` 的一部分（`source/SOURCE_POLICY.json` 只允許 `taedlar/es2_mudlib`）。

## 使用規則

- 只當參考：要把內容做進遊戲，先列出來給使用者確認，確認後才製作；不直接改 `source/`。
- 每個來源的原始說明都寫著「DOCUMENTED，需對照原始 mudlib 才能當正式設定」，數值與說明可能與現行版本不同。
- 玩家整理的文字可能有錯字、斷行殘缺、版本差異；引用房間敘述前，必須回到原檔核對。

## 整理方式

- 只保留純文字。原始 HTML、圖片、離線版網頁、重複的 zip 都沒有放進來。
- `es2_pal/` 原為 Big5，已轉成 UTF-8；檔案裡的顏色碼 `[1;34m` 等保留文字，只移除了不可見的控制字元。
- 檔名中原本被轉碼成 `#U5347` 的字已還原成中文；過長的檔名縮短，但日期保留。
- 每個網站的原始網址與抓取日期，在各檔案開頭的 front matter（`URL:`、`Retrieved:`）。

## 字元相容

若把其中文字做進遊戲，要先通過 `python3 tools/check_big5_text.py`。
