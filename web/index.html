樣式寫法說明

* 任意文字　? 任一個字　%d 數字　%n 可帶正負號的數字　%w 一個詞（中英文字、數字）　%s 空白　%x 非空白字元

( ) 擷取文字，指令裡用 %1～%9 帶入（%0 是整段符合的文字）　{甲|乙} 二選一　[abc] 字元集合　^ 行首　$ 行尾　~ 讓下一個字元照字面比對

例：樣式 ^(%w)告訴你：(*)$，指令 reply 收到：%2。指令可用 ; 串接，也可以寫 #tr off。

網頁指令（輸入欄、觸發、計時器都能用，不會送到遊戲）：#wa 2000 等 2 秒再送後面的指令（單位毫秒，只寫 #wa 是 1 秒）　#3 e 同一個指令重複 3 次　#dis 中斷連線（不會自動重連）　#con 重新連線　#t+ 類別／#t- 類別 開關某一組觸發　#sh 文字 只在自己畫面印一行字。例：n;#wa 2000;get all;s。

同一行符合多個觸發時全部都會執行。自動指令一秒內超過 20 個會自動暫停，避免觸發互相引發造成無限循環。輸入密碼或編輯文章時不會自動送指令。

指令寫法說明

條件　#if (條件) {成立時} {不成立時}，後面的 {…} 可省略。例：#if (@hp < 50) {eat dumpling} {#sh 還撐得住}

條件可用 = != > < >= <= 比較，& 而且、| 或者、! 不是，+ - * / 計算（除法取整數）、% 取餘數，括號分組。文字有空白時用 "雙引號" 括起來。

重複　#loop 5 {指令} 重複 5 次，#loop 1,5 {say %i} 的 %i 是第幾次；#while (條件) {指令} 條件成立就一直做；#case 2 {甲} {乙} {丙} 執行第 2 個；#abort 停止後面的指令。

變數　#var 名稱 值 設定（值有空白用 {} 括起來）、#unvar 名稱 刪除、#var 列出全部；指令裡寫 @名稱 帶入。#math 名稱 運算式 把結果存進變數，#add 名稱 數字 加上去（例：#add kills 1）。

角色狀態　@hp 形體、@jing 精、@qi 氣、@shen 神、@food 食物、@water 飲水、@fatigue 疲勞，後面加 max 是最大值（例：@qimax）。也可以寫 @gin、@kee、@sen。

縮寫　#alias kk {kill %1;perform %1}，之後打 kk 野狗；%1～%9 是後面的字，%* 是全部。縮寫裡沒寫 % 的話，後面的字接在最後。#unalias kk 刪除、#alias 列出全部。

其他　.3n2e 快速移動（等於 n;n;n;e;e，斜角寫 .2(ne)）；#trigger {樣式} {指令} 類別 新增觸發、#untrigger {樣式} 刪除；#alarm 30 {指令} 30 秒後執行一次；#echo 文字 只在自己畫面顯示；#beep 叫一聲。

函數　%len(文字) 字數、%random(10) 0～10 的亂數（%random(1,6) 1～6）、%time 現在時間、%left(文字,2)／%right(文字,2) 左邊／右邊幾個字、%pos(找的字,文字) 在第幾個字（沒有是 0）、%eval(運算式) 計算、%if(條件,是,否)。

隱藏與上色　#gag {樣式} 之後符合的行不顯示、#ungag {樣式} 取消；觸發的指令裡單獨寫 #gag 會隱藏觸發的那一行。#color {樣式} 亮黃 把符合的文字上色、#uncolor {樣式} 取消；顏色可用 紅 綠 黃 藍 紫 青 白 灰 橘 粉紅，前面加「亮」更亮，也可寫英文 red、hi yellow。

大括號裡的 ; 不會拆開；要送出 ; { } @ % 本身時，前面加 ~。一串指令沒有 #wa 卻處理超過 2000 步（例如 #while 停不下來）會自動停止。
